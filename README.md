# 🩺 Hypertension Prediction Using Machine Learning

## 📌 Project Description
This project focuses on predicting the likelihood of hypertension (high blood pressure) using machine learning techniques, specifically the **Random Forest algorithm**.

Hypertension is a major health issue and a leading risk factor for serious conditions such as heart disease, stroke, and kidney failure. It is often called a *“silent killer”* because it may not show clear symptoms in the early stages.

The main objective of this project is to develop a predictive model that can identify individuals at risk of hypertension by analyzing various health and lifestyle factors such as:

- Age  
- Body Mass Index (BMI)  
- Stress levels  
- Sleep duration  
- Family history  
- Smoking habits  
- Physical activity  

As a healthcare AI and data science student, this project addresses a real-world problem where technology can help improve people's health. Early prediction of hypertension enables timely medical intervention and lifestyle changes, reducing the risk of severe cardiovascular diseases.

---

## 🎯 Objectives
- Predict whether a person has hypertension (Yes/No)
- Identify high-risk individuals using health data
- Support early diagnosis and preventive healthcare
- Improve awareness of hypertension risks

---

## ⚙️ Project Workflow

1. **Problem Definition**  
   Identify hypertension based on health and lifestyle features.

2. **Data Collection**  
   Gather dataset with input features and target variable (Hypertension: Yes/No).

3. **Data Preprocessing**
   - Convert categorical data into numerical format  
   - Handle missing values  
   - Remove duplicate entries  

4. **Feature Selection**
   Important features include:
   - Age  
   - BMI  
   - Family History  
   - Lifestyle factors  

5. **Train-Test Split**
   - 80% Training Data  
   - 20% Testing Data  

6. **Model Selection**
   - Random Forest Algorithm  

7. **Model Training**
   - Build multiple decision trees  
   - Combine outputs for better accuracy  

8. **Prediction**
   - Predict hypertension using test data  

9. **Model Evaluation**
   - Accuracy  
   - Precision  
   - Recall  
   - Confusion Matrix  

---

## 🤖 Why Random Forest?

Random Forest is chosen because it provides:
- High accuracy  
- Reduced overfitting  
- Better handling of complex relationships  
- Robust performance on healthcare data  

---

## ⚠️ Why Other Algorithms Are Not Preferred?

- **Linear Regression**  
  Not suitable because it is used for continuous output, not classification.

- **Logistic Regression**  
  May not perform well with complex relationships in healthcare data.

- **Decision Tree**  
  Prone to overfitting, leading to poor performance on new data.

- **K-Nearest Neighbors (KNN)**  
  Slower with large datasets and sensitive to noise and irrelevant features.

👉 Therefore, **Random Forest** is a more reliable and efficient choice for this project.
